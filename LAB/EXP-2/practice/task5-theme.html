Background colors

The page uses var(--bg). The button changes only the value of --bg.

Text colors

Headings use var(--ink) and this text uses var(--ink-soft).

Card styles

Cards use var(--card) and var(--rule) for the border.

How it works

The button sets data-theme="dark" on the <html> element. The rule :root[data-theme="dark"] then gives new values to the same custom properties, so every element changes at once. The choice is saved in the browser, and on the first visit the page follows the system setting (prefers-color-scheme).
